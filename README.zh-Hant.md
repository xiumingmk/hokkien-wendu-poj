# 泛閩南語白話字綜合音系自動推導器
## Pan-Min-Nan POJ diasystem auto-deriver

[English](README.md)

輸入一個漢字，它就依該字的中古音，推出閩南語文讀音，以白話字（POJ）書寫。

```
學而時習之，不亦說乎      ha̍k jî sî si̍p chi, put e̍k ia̍t hô͘
床前明月光，疑是地上霜    chhông chiân bêng goa̍t kong, gî sǐ tē siāng song
關關雎鳩，在河之洲        koan koan chhir kiu, chǎi hô chi chiu
```

## 用途

閩南語的漢字大多有兩種讀法。白讀是口語的說法：「大」平常說 *tōa*。文讀是讀古文、吟詩時用的讀法：「大學」的「大」讀 *tāi*。辭典只為一部分的字記下文讀音，而且各家常有出入，因為廈門、臺灣、漳州、泉州、檳城的讀法各有不同。

這個腳本為每個字提供一個前後一致的文讀音：可以用來以閩南語朗讀古文、填補辭典的空缺，或作為學習工具的讀音層。它的做法跟古代韻書相同：從該字的中古音（即《廣韻》反切）出發，套用「每個中古音在閩南語文讀中會變成什麼」的規則，再查一份簡短的例外表，處理閩南語不照自身規律的字。

本腳本供 [NK2028 的 tshet-uinh-deriver](https://nk2028.shn.hk/tshet-uinh-deriver/)（由中古音推導讀音的工具）使用。

## 為什麼是「鑲嵌」

沒有任何一個閩南語方言保留了中古漢語的全部對立，但合起來保留了不少。本腳本只遵守一條原則：**只要任何一個參照方言保留某個對立，就保留；沒有任何方言保留的，絕不憑空創造。** 參照方言為廈門、臺灣、漳州、泉州、檳城，第六聲另據鹿港。

| 保留的對立 | 保留者 | 例子 |
|---|---|---|
| 陽韻 *iang* 對 東三／鍾 *iong* | 漳州 | 良 liâng ≠ 龍 liông |
| 魚韻 *ir* 對 虞韻 *u* | 泉州（漳州也有分，讀 *i*） | 居 kir ≠ 拘 ku |
| 侯韻 *io* 對 模韻 *o͘* | 泉州 | 樓 liô ≠ 盧 lô͘ |
| 痕／殷韻 *irn* 對 魂 *un* 與 真 *in* | 泉州（漳州、廈門各分一邊） | 恩 irn ≠ 溫 un ≠ 因 in |
| 日母 *j* 對 來母 *l* | 漳州、檳城 | 人 jîn ≠ 鄰 lîn |
| 全濁上 第六聲 對 第七聲 | 鹿港、泉州、南安、惠安 | 是 sǐ ≠ 示 sī |
| 灰韻 *oe* 對 微韻 *ui* | 漳州、泉州 | 灰 hoe ≠ 揮 hui |
| 侵韻 莊組 *om* 對 侵韻 *im* | 雅俗通與彙音妙悟（箴字母） | 森 som ≠ 心 sim |

在 3,804 個小韻上，這樣共得 1,759 個相異音節；早先以廈門為本的版本只有 1,396 個。結果不是任何一個真實存在的方言，也不是某一歷史層次的重建，因為各方言的文讀層並非作為一個整體系統借入（楊秀芳 1982）。但它所做的每一個區分，都是某處真實的說話者所做的區分。

## 準確度如何？

對你實際會遇到的字，它給出的幾乎都是閩南語中真實存在的讀音。

| | 古文實際行文 | 最常用 1,000 字 | 最常用 3,000 字 | 全部 7,683 字 |
|---|---|---|---|---|
| 只用規則 | 98.4% | 98.0% | 95.0% | 86.5% |
| 規則＋例外表 | **99.8%** | **100%** | **98.1%** | 88.5% |

某字的推導讀音，若其聲母與韻母都出現在該字某個有紀錄的閩南語讀音中，就算吻合。聲調不計，因為依設計，聲調一律取中古調類。測試範圍是《廣韻》只有一讀、且在辭典或調查表中有資料的 7,683 個字。

最後一欄看起來不理想，但它把「蠆」（蠍子）和「之」算成同等份量。第一欄則依每個字在中國哲學書電子化計劃（ctext.org）語料中出現的次數加權，語料約 570 萬字。最常用的 1,000 字占這些文字的 88%，最常用的 3,000 字占 98%。目前仍有 882 個字不吻合：其中沒有一個屬於最常用的 1,000 字；有 824 個（93%）在最常用的 3,000 字之外；有 357 個在語料中完全沒有出現。

附註：
- 「最常用」依文言字頻排序。
- 《廣韻》有多讀的字（不、大、長、行）不計分，因為哪個讀音正確要看上下文。計分的一讀字占實際行文的 71%。
- 例外表是根據同一批資料選出的，所以第二列屬於樣本內數字。為了測試規則在沒看過的字上的表現，我們用一半的字重新生成韻母表，再拿另一半的字評分，結果是 86.1%（全部）、96.1%（最常用 1,000 字）、89.0%（最常用 3,000 字）；而在用來生成的那一半上是 85.6%。可見生成的韻母表並沒有過度擬合。

## 十五音系統

有四個來源同屬一個韻書系統，即漳州與廈門的十五音。本文稱此系統為**十五音系統**（英文為 rime-book tradition）：

- 《彙集雅俗通十五音》（謝秀嵐，1818），漳州韻書
- Medhurst 的 Hok-këèn 辭典（1832；使用的是 1837 漳浦表），依十五音編排
- 《廈門音新字典》（甘為霖，1913），即甘字典，依同一系統編成
- 維基詞典，常抄錄甘字典

只有這四者支持的讀音，不算獨立佐證，不論它們多麼一致。系統以外的來源有：Douglas（1873）、Macgowan（1883）、1604 年馬尼拉紀錄、《臺日大辭典》、教育部、MCPDict 現代調查。《彙音妙悟》是另一個泉州韻書系統，不計入其內。

## 例外表修正什麼

規則描述的是一般規律，但有約兩百個字不照規律走，其中不少是常用字。選項 **例外** 開啟時（預設為開），約 214 個這樣的字（242 個讀音，另加 56 個異體字形）會改用閩南語實際使用的音節。例外只替換聲母與韻母，聲調一律維持中古調類。關閉此選項，即可看到純規則的輸出。

| 字 | 反切 | 規則給出 | 套用例外 | 規則為何不中 |
|---|---|---|---|---|
| 不 | 分勿切 | hut | **put** | 非母一般變為 h-（分 hun、法 hoat、風 hong），但這個排名第二的常用字，在所有閩南語來源中都保留了古老的 p-。 |
| 大 | 唐佐切 | tō | **tāi** | 閩南語讀這個「大」時，用的是它的另一個反切（徒蓋切）tāi。沒有任何來源讀 tō；口語說 tōa。 |
| 萬 | 無販切 | boān | **bān** | 元韻合口在微母後一般讀 oan（晚 boán），但「萬」在所有閩南語來源中都讀 bān。 |
| 乃 | 奴亥切 | lái | **nái** | 泥母一般與來母合流為 l-（奴 lô͘、能 lêng），但「乃」保留了 n-。 |
| 馬 | 莫下切 | bá | **má** | 明母一般讀 b-（麻 bâ），但「馬」保留了 m-。 |
| 鳥 | 都了切 | tiáu | **niáu** | 各來源讀 niáu（或 jiáu），不是反切的 t-。 |
| 頭 | 度侯切 | tiô | **thiô** | 定母一般不送氣（豆 tiō、徒 tô͘），但「頭」各地都送氣（thiô、thô͘、thâu）。 |
| 內 | 奴對切 | lūi | **lōe** | 灰韻在端組與來母後讀 ui（對 tùi、雷 lûi），但「內、退、罪」讀 oe。 |
| 米 | 莫禮切 | bé | **bí** | 齊韻在脣音後保留為 e（迷 bê、謎 bē、陛 pě），但「米、閉」讀 bí、pì。 |
| 某 | 莫厚切 | bió | **bó͘** | 泉州侯韻讀 io（口 khió、母 bió），但不及於「某、畝、牡、戊」，這幾個字各地都讀 bó͘。 |
| 謹 | 居隱切 | kírn | **kín** | 泉州痕／殷韻讀 irn（根 kirn、斤 kirn），但在泉州本身就不規則：「謹」讀 kín，「隱」讀 ún。 |
| 雄 | 羽弓切 | iông | **hiông** | 云母一般沒有聲母（王 ông、雲 ûn），但「雄、熊」有 h-。 |
| 貞 | 陟盈切 | teng | **cheng** | 知母一般讀 t-（知 ti、中 tiong），但「貞」讀 cheng。 |
| 完 | 胡官切 | hoân | **oân** | 匣母一般讀 h-（寒 hân、換 hoān），但「完」沒有聲母。 |

只有當規則輸出不是任何閩南語方言中該字實有的音節時，才使用例外。替換用的是與規則輸出最接近的已記錄音節（聲母、韻母改動最少者），並優先採用辭典標為文讀的讀音。若沒有提供字頭，就由規則決定。

## 為什麼罕用字不中，又為什麼規則讀音常常是較好的推測

剩下不吻合的字，幾乎都是罕用字。部分原因在規則本身：規則是依資料充足的字調整的，所以罕見小韻的推導可能出錯。但對罕用字來說，有紀錄的讀音往往比反切還不可靠：

- **依聲符讀（有邊讀邊）。** 「蠆」（蠍子；丑犗切，應讀 thài）記作 bān、māi，即同聲符的「萬」、「邁」的讀音，也記作 chhài。「痏」（瘡痏；榮美切，應讀 úi）只記作 iū，依其聲符「有」（iú）讀，而且只見於一部辭典。
- **與形近字相混。** 「茍」（紀力切，應讀 kek）記作 kó͘，那是「苟」（古厚切）的讀音。
- **讀成它所代替的字。** 「寔」（實也；常職切，應讀 se̍k）記作 si̍t，是「實」的讀音。「寘」（置也；支義切，應讀 chì）記作 tì，是「置」的讀音。「沖」（直弓切，應讀 tiông）記作 chhiong，是與它常互通的「衝」的讀音。
- **該字沒有任何來源記錄的鑲嵌韻母。** 882 個不吻合的字中，有 152 個用了鑲嵌韻母（ir、irn、iang、io、om），而這些字只在不區分該韻母的方言中有紀錄。例如「姤」推出 kiò，各來源記作 kò͘。

罕用字的證據也很單薄。不吻合的罕用字中，有 72% 只見於十五音系統：雅俗通、Medhurst（依十五音編排），以及大多沿襲它們的甘字典與維基詞典。吻合的罕用字中，這個比例是 51%。另外，不吻合的罕用字有 45% 只有一個來源，吻合的罕用字則是 23%。

所以例外表對罕用字特別嚴格。最常用的 3,000 字以外，只有當讀音在十五音系統以外也有佐證時（教育部辭典、臺日大辭典、Douglas、Macgowan、1604 年馬尼拉紀錄或現代調查），該字才列入例外。之後每一列都經過人工審閱，刪去以罕用字書寫的口語詞（尪 ang）、帶華語色彩的讀音（傻 sa），以及規則已處理之字的異體（猪＝豬）。其餘一律採用反切讀音。對於一個你很少會聽到人朗讀的字，合乎音系的讀音，比十五音韻書可能自己也只是猜測的讀音，更值得採用。

## 使用方式

**在瀏覽器中。** 開啟 [tshet-uinh-deriver](https://nk2028.shn.hk/tshet-uinh-deriver/)，新增自訂腳本，貼上 `hokkien-wendu-poj.js`。

**在 Node 中**（tshet-uinh 0.15.x）：

```js
import TshetUinh from 'tshet-uinh';            // npm install tshet-uinh@0.15.4
import fs from 'fs';

const code = fs.readFileSync('hokkien-wendu-poj.js', 'utf8');
const derive = new Function('TshetUinh', '選項 = {}', '音韻地位', '字頭 = null', code);

for (const { 音韻地位 } of TshetUinh.資料.query字頭('頭'))
  console.log(derive(TshetUinh, { 例外: true }, 音韻地位, '頭'));   // thiô
```

**輸出。** 輸出為白話字，含慣例的擴充符號：o͘、ir、irn、eng/ek。聲調：第一聲不標，第二聲 á，第三聲 à，第四聲不標（以 -p/-t/-k/-h 結尾），第五聲 â，第六聲 ǎ，第七聲 ā，第八聲 a̍。聲調一律取中古調類（清／濁 × 平上去入），全濁上為第六聲；因此在某些方言中已改調的字，這裡仍保留中古調（係 hè，多數方言讀 hē）。

## 逐行註解本

`hokkien-wendu-poj.annotated.js` 是同一個腳本，每一行程式碼都附有中文說明。每一列規則都寫出：它做什麼、為什麼這樣寫、依據哪些來源，以及實測的數字：它決定多少個小韻，只刪掉這一列時這些小韻會怎麼讀。自動生成的列附甘字典票數；例外表的每一列附反切、規則讀音、替換讀音與佐證來源。檔首是決策紀錄：試過、採用、放棄了什麼，附數字。程式碼與主檔完全相同，輸出也相同；已對每個小韻與資料中的每個字檢查過，例外開與關都一樣。兩檔若有出入，以主檔為準。

- **Macgowan, John. 1883. English and Chinese Dictionary of the Amoy Dialect.** Amoy: London Missionary Society [出版者：unchecked；作者與年份：SOAS 紀錄 https://library.soas.ac.uk/Record/PCE.FMC.3.03.01 ]。經 MCPDict「1883厦門（英厦辭典）」表使用。[2,896；65] 十九世紀的廈門話，在十五音系統之外。
- **黃謙. 1800. 彙音妙悟.**（泉州韻書，不屬十五音系統）[unchecked]。未使用機讀副本，內容經由下列洪 1996 讀取。它是設計中的泉州一方：書中把「母、某、謀、牟」放在與侯韻同屬的鉤韻，支持明母侯韻同樣讀 *io*；又把登／庚二／耕分開讀 *irng*。我們曾試過 *irng* 的選項，後來移除，因為幾乎沒有人這樣讀，而且吻合度降低 2 個百分點。

### 現代調查表

- **osfans（編）. 2016-. 漢字音典（MCPDict）.** https://github.com/osfans/MCPDict ，tools/tables/output/ 。共有 24 個現代閩南語表：泉州片的泉州、晉江、南安、永春、德化、惠安、安溪、金門、石獅；廈門；漳州片的漳州、長泰、華安、南靖、漳浦、雲霄、東山、詔安、平和；臺灣的臺北、嘉義、澎湖、高雄；以及檳城。每表 1,578 至 5,972 字，並各自標有文白。調查表中的讀音，若被該表標為文讀、屬歷史文獻，或有兩個表一致，即算文讀。各方言保留哪些對立，就是從這些調查表看出來的：*io* 見於泉州、晉江、南安、惠安；第六聲見於泉州、南安、惠安；*irn* 見於南安、惠安、永春、德化；*iang* 見於漳州、漳浦、東山、華安、南靖、長泰、雲霄、平和；*j* 見於檳城與漳州。四個潮州話表（潮州、汕頭、揭陽、潮陽）不是參照方言，用法見下文「潮州話的用法」。
- **mogher.com.** https://www.mogher.com/ 。一個潮州話發音網站，提供 850 個其他來源皆無的字的潮州話讀音。與其他潮州話資料一樣，它不是參照方言：沒有任何規則依它而定，輸出的音節也不取自它（見下文）。其中「萬 buāng」一讀為手動補入。

**潮州話的用法。** 潮州話不是參照方言：沒有任何規則依它而定，腳本輸出的音節也不取自它。潮州話讀音來自三處：MCPDict 的四個潮州話表、維基詞典與 mogher.com。它們只在檢驗時起三個小作用：
1. 若規則輸出不是任何閩南語來源所有的音節，但潮州話有，且沒有閩南語來源反對，該字就交給規則，不另列例外。
2. 潮州話讀音可以佐證只有一個閩南語來源的例外替換讀音。
3. 只有潮州話資料、沒有閩南語資料的字，也能被檢驗。

上文的準確度數字只計閩南語讀音。

## 細節（給熟悉《廣韻》的讀者）

**聲母**（聲母表），手寫，先中先用。
- 非敷奉讀 h-（風 hong、法 hoat），微母仍讀 b-（無 bû、文 bûn）。
- 幫滂並讀 p/ph/p，並母宵韻 A類讀 ph-（瓢 phiâu）。
- 明母讀 b-，但豪韻（毛 mô͘）及蟹攝一／二等去聲（賣 māi）讀 m-。
- 端透定與知徹澄讀 t/th/t，泥孃來皆讀 l-。
- 精組、莊組、章組讀 ch/chh/s，例外如下：崇母平聲讀 chh（柴 chhâi），崇母止攝讀 s（士 sǔ），精母東三與從母陽韻平聲讀 chh，船母與常母讀 s。
- 日母讀 j-。
- 見溪羣疑讀 k/kh/k/g，在 o 與 o͘ 前讀 ng-。讀 kh- 的有：魂韻見母平聲（昆 khun）、元韻見母入聲（厥 khoat），以及羣母深／咸攝平／上聲（琴 khîm、儉 khiǎm）。
- 曉匣讀 h-。
- 影云以無聲母，例外如下：云母蒸韻讀 h-（域 he̍k），以母虞韻與祭韻合口讀 j-（愉 jû、銳 jōe）。

**韻母**（韻母表），先中先用：
1. 鑲嵌：陽韻開口（非莊組）→ *iang/iak*；侯韻及尤韻莊組／明母 → *io*，但心母、生母（叟 só͘）及侯韻幫滂並（部 pǒ͘）除外；痕／殷 → *irn/irt*。這幾條規則無條件適用。
2. 手動：保留對立的手寫規則。魚韻 → *ir*，但莊組 → *o͘*（初 chho͘）。灰韻 → *oe*，但端組、精組、來母 → *ui*（頹 tôe 除外）。侵韻莊組舒聲 → *om*。豪韻明母 → *o͘*。江韻莊組 → *ong*。齊韻幫組 → *e*。較小的規則：江韻與登韻幫組入聲 → *ok*（剝 pok、北 pok），微韻明母 → *i*（微 bî），夬韻合口 → *oai*（快 khoài）。
3. 補充：四條覆蓋生成表的手寫規則。
4. 自動：甘字典中每個韻／呼／等／類的最常見文讀韻母，由程式生成，不手動編輯。
5. 後備：按韻的後備規則。

入聲音節與其對應平聲的韻／等／呼相同，所以一張表通用於四聲，韻尾事後再轉換。

**聲調**：清平 1、濁平 5、全濁上 6、其他上聲 2（次濁上與清上合併，各參照方言皆然）、清去 3、濁去 7、清入 4、濁入 8。

**各鑲嵌特徵增加的區別**（相異音節數，對 3,804 個小韻）：第六聲 +106；陽 *iang* +61；日 *j* +49；魚 *ir* +47；侯 *io* +43；痕殷 *irn* +23；灰 *oe* +11；齊幫組 *e* +8；侵莊組 *om* +8。合計 1,759；不含 iang/io/irn 為 1,632。若只對照甘字典的廈門韻母（留出測試），不含 iang/io/irn 時韻母吻合 91.7%，含之為 87.1%。這 4.6 個百分點的落差，就是保留廈門所沒有的對立所付出的代價。

**仍合併者**，因為沒有任何參照方言在文讀中區分它們，或白話字無法書寫其差別：支／脂／之（*i*）、歌／豪（*o*）、清／青／蒸／庚三與登／庚二／耕（*eng/ek*）、仙／先（*ian*）、覃／談（*am*）、知＝端（*t*）、精＝章＝莊（*ch*）、邪＝心（*s*）、侯韻幫滂並＝模（*o͘*）、真韻 B類見組＝A類（*in*）、止攝精莊＝虞韻精莊（*u*）。

**已知限制。**
- 聲調一律取中古調類，所以轉入他調的讀音仍保留舊調：係 hè（一般讀 hē）、踏 thap（ta̍p）、站 chàm（chām）、懈 hài（hāi）。
- 辭典讀音屬於異體字或另一個音韻地位上另一詞的字，刻意交給規則處理（粗、唇、玆、庄、鎗）。

**給修改腳本者的備註**（tshet-uinh 0.15.4）：
- `音韻地位.判斷(rules, throws)` 的第二個參數是 `throws`，不是預設值；傳入錯誤字串，未涵蓋的音韻地位才會明確報錯。
- 規則的結果不可以是陣列，否則會被當成巢狀規則清單。
- 標籤必須使用繁體字：羣母而非群母，常母而非禪母，以及全濁／清音／濁音。
- 缺少音韻地位時列出選項，格式為 `['key|標籤\n說明', 預設值]`，其值以 `選項.key` 傳入。字頭即使用者輸入的字。
